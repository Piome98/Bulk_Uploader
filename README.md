# Bulk Uploader

Copilot, ChatGPT, Claude, Gemini 같은 LLM 채팅은 한 번에 올릴 수 있는 파일 수가 제한돼 있습니다.
이 프로그램은 파일을 **3개씩(개수 변경 가능)** 나눠 자동으로 올리고, 배치마다 `.` 메시지를 보내면서 끝까지 이어 줍니다.

- 설치가 필요 없는 실행 파일 하나: `dist/BulkUploader.exe` (약 50KB)
- Windows 10/11에 기본으로 들어 있는 .NET Framework 4.x로 실행됩니다.

## 다운로드

**[BulkUploader.exe 내려받기](https://github.com/Piome98/Bulk_Uploader/raw/main/dist/BulkUploader.exe)** — 받은 파일을 바로 실행하면 됩니다.

## 사용 방법

1. `BulkUploader.exe`를 실행합니다.
2. 올릴 파일이나 폴더를 목록에 끌어다 놓습니다. ([파일 추가]/[폴더 추가] 버튼을 써도 되고, exe 아이콘 위에 파일을 끌어다 놓아도 됩니다.)
   목록 순서대로 묶이므로 필요하면 ▲/▼ 버튼이나 [이름순 정렬]로 순서를 바꿉니다.
3. 브라우저에서 채팅 화면을 엽니다.
4. 다음 중 한 가지 방법으로 시작합니다.
   - 채팅 입력창을 클릭한 상태에서 **F9**를 누릅니다.
   - **[▶ 시작]**을 누른 뒤 카운트다운(기본 3초)이 끝나기 전에 채팅 입력창을 클릭합니다.
5. 이후에는 아래 과정이 반복됩니다.
   `파일 3개 붙여넣기(Ctrl+V) → 업로드 대기 → "." 입력 → Enter → 응답 대기 → 다음 3개`

| 단축키 | 동작 |
|---|---|
| F9 | 시작 / 일시정지 / 재개 (수동 모드에서는 다음 배치) |
| F10 | 중지 |

## 설정

| 항목 | 기본값 | 설명 |
|---|---|---|
| 한 번에 올릴 파일 수 | 3 | 서비스가 허용하는 파일 수에 맞춥니다. |
| 배치마다 보낼 메시지 | `.` | 파일과 함께 보낼 메시지입니다. |
| 마지막 배치 메시지 | (비어 있음) | 예: `지금까지 올린 파일 전부 요약해줘`. 비워 두면 위 메시지를 그대로 씁니다. |
| 전송 키 | Enter | Ctrl+Enter로 전송하는 서비스라면 바꿉니다. |
| 붙여넣기 후 업로드 대기 | 5초 | 파일이 크거나 메시지가 입력창에 남아 있으면 늘립니다. |
| 다음 배치로 넘어가기 | 자동, 20초 | AI 응답이 끝나기 전에 다음 파일이 올라가면 시간을 늘리거나 **수동** 모드를 씁니다. 수동 모드에서는 응답이 끝날 때마다 F9를 누릅니다. |

설정은 `%APPDATA%\BulkUploader\settings.ini`에 자동으로 저장됩니다.

## 안전장치

- 진행 중에 다른 창으로 전환하면 다른 곳에 붙여넣지 않도록 **자동으로 일시정지**됩니다. 채팅 입력창을 다시 클릭하고 F9를 누르면 멈춘 곳부터 이어집니다.
- 작업이 끝나면 원래 클립보드에 있던 텍스트를 복원합니다.

## 붙여넣기로 파일이 첨부되지 않는 경우

오른쪽 아래 **수동 모드**의 파란 영역을 마우스로 끌어 채팅창에 놓으면 현재 배치의 파일이 한 번에 첨부됩니다.
놓은 뒤에는 자동으로 다음 배치로 넘어갑니다. 넘어가지 않으면 [다음 배치 ▶]를 누릅니다.

## 다른 사람에게 배포할 때

`dist/BulkUploader.exe` 파일 하나만 보내면 됩니다.
코드 서명이 없는 프로그램이라 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다. 이때는 **추가 정보 → 실행**을 누릅니다.

## 직접 빌드하기

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Windows에 기본으로 들어 있는 `csc.exe`(.NET Framework 4.x)로 `src/BulkUploader.cs`를 컴파일해 `dist/BulkUploader.exe`를 만듭니다. 따로 설치할 것은 없습니다.
